# Hard Gates Summary

Do not proceed past these checkpoints without explicit user approval ("yes", "approved", or equivalent):

1. **Requirements & success criteria** (kickoff Phase 1)
2. **Data model review** (kickoff Phase 2) — use `docs/schema-review-template.md`
3. **Architecture & technology selection** (kickoff Phase 3) — use `docs/architecture-decision-template.md`
4. **Build plan** (kickoff Phase 4)
5. **Each build phase completion** — use `docs/phase-completion-template.md`

A gate is complete only when both are true:

- explicit approval received, and
- approval logged in `docs/gates.md`.

Maintain throughout the project:

- `docs/gates.md`
- `docs/phase-status.md`
- `docs/definition-of-done.md`

Before moving to the next phase, provide:

1. What was delivered
2. Test results and acceptance status
3. Gate approval status (with `docs/gates.md` entry)
4. Updated `docs/phase-status.md` status
5. Any risks/deviations and planned mitigation
